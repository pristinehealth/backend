SEO Plan — Combined Strategy & Implementation

Merges the marketing/SEO strategy (two acquisition systems: Facility Staffing + Home Care, service × customer × geography) with a technical audit of the Next.js app that must host it.

Repo: JOHN_KARIUNGI/backend (Next.js App Router) · Reference doc, not code · Last updated 2026-08-27
The one thing to understand first. The strategy is entirely buyer-facing — facility administrators and families looking for care. This repo today is a candidate-facing ATS whose public pages (/, /jobs, /jobs/[id]) are all client-rendered with no structured data, no sitemap/robots, and thin metadata — so search engines currently see almost nothing. The plan below builds the buyer marketing site as new server-rendered pages in this same app, on the SEO foundation that's currently missing. Candidate/job pages are secondary — the strategy is explicit that nurse/caregiver job-seeker traffic is not the goal.

2 · Site architecture & routes

Build the strategy as a data-driven taxonomy (service × customer × geography), not ~40 hand-coded pages — hand-coding invites the "doorway/duplicate" penalty. Each entry (slug, title, h1, metaDescription, keywords[], bodySections[], faqs[]) renders a unique, server-rendered, statically-generated page.

# Buyer marketing site (NEW — server components, generateStaticParams + generateMetadata) /facility-staffing/ /facility-staffing/[service] cna · lpn · rn · med-tech · caregiver · 1-to-1-support · assisted-living · skilled-nursing · memory-care · behavioral-health · emergency-staffing /home-care/ /home-care/[service] personal-care · companion-care · respite-care · dementia-care · overnight-care · 24-hour-care · post-hospital-care · 1-to-1-care /locations/[city] seattle-wa · bellevue-wa · tacoma-wa · everett-wa · renton-wa · kent-wa · auburn-wa · federal-way-wa · lynnwood-wa /resources/ · /resources/[slug] # content hub (facilities + families) # Existing (candidate ATS — gets JobPosting schema, secondary priority) / · /jobs · /jobs/[id] # Auth-gated — robots DISALLOW /dashboard · /onboarding · /jobs/track · /api
City hubs, not cloned pages. Each /locations/[city] is one page linking to every relevant service (facility + home care) with genuine local info — not "CNA staffing Seattle / …Bellevue / …Tacoma" with only the city swapped. Scaling to a new city = one data entry.

3 · SEO technical foundation CODE

Applies to every page above; the marketing strategy can't rank without it.

  • Server-render the public pages (server component fetching Mongo directly; a small client child keeps interactive bits like the apply form). Add ISR (revalidate). prerequisite
  • NEXT_PUBLIC_BASE_URL + metadataBase in root layout.
  • Reusable JSON-LD components (see §8) rendered server-side.
  • sitemap.ts — enumerate all taxonomy pages + open jobs from Mongo.
  • robots.ts — allow marketing routes; disallow /dashboard, /onboarding, /jobs/track, /api; point to sitemap.
  • generateMetadata per page (title/description/canonical/OG) from the taxonomy data.
  • OG images — per-service default + per-job imageUrl; fix root title/description to a careers+care pitch.

11 · Off-site — GBP, reviews, Ads OPERATIONAL

Google Business Profile

  • Business name must be the real name: Pristine Health — do not keyword-stuff ("Pristine Health CNA Staffing Home Care Seattle").
  • Set up to 20 service areas (cities served).
  • Put keywords under Services: Home Care, Senior/Personal/Companion/Respite/Dementia/24-Hour Care, Healthcare Staffing, CNA/Caregiver/Med Tech/LPN/RN Staffing, 1:1 Patient Support, Temporary Healthcare Staffing.

Reviews

Ask "What service did Pristine provide, and what stood out?" — natural mentions ("helped us find a caregiver for my mother in Bellevue" / "CNA coverage for our assisted living community") build local relevance far better than "Great company!". Don't script the wording.

Google Ads (align with SEO landing pages)

Point ads to the matching page ("CNA staffing agency Seattle" → Seattle CNA staffing page, not the homepage). For home-care paid campaigns, add negative keywords to filter job seekers: jobsjobcareer(s)hiringsalaryapplicationapplyCNA classestrainingcertificationresumeindeed
